# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| 2.0     | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security vulnerability, please report it to us: 
- **Email**: security@yothabo.com
- **Mailing List**: security@yothabo.com

## Security Practices

- Always validate input before processing.
- Implement proper authentication and authorization checks.
- Regularly update dependencies to mitigate vulnerabilities.
- Use secure coding practices to avoid common vulnerabilities such as XSS, CSRF, and SQL Injection.
